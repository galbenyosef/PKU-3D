# 模型现状与已知缺口

PKU-3D 使用公开地图、影像和照片建立展示模型。可辨细节的局部修补，不代表整栋测绘、隐藏立面还原或全部入口验收。源文件保留逐处依据和不确定性；原始研究材料、逐轮实验报告与中间截图留在本地，不随仓库发布。

## 本次更新

- 增补校园建筑、庭院、入口、景物的参考拟合与几何接合修补；运行时保留原始模型细节、图像分辨率、阴影、反射与抗锯齿。
- 近期局部交付包括健斋红窗、外国语学院北侧开放梯间及玻璃棚、勺园6号餐厅入口；后续修补燕南园57号门墩可见浮雕、勺园5号最高阶与门的接续、人文学苑三处檐口及章桂堂台明下缘。
- 西校门牌匾恢复原生字形比例，门身竖向比例另行调整；燕南园55号三块台基下延至地面。照片拟合仍有局限；被遮挡的檐口与台明部分只验证几何闭合，未获得直接视觉证实。
- 缓存启动跳过无用道路网格计算；正式性能结果与未通过项目见[性能说明](performance.md)。

## 数量口径

原明确范围为87个对象、90条细项，其中1条已关闭，40个主要对象的43条细项仍缺资料，46个边缘对象暂缓。局部交付没有把其余细项改成完成。另85个待参考对象属于其他范围，并非从这87个对象中转出。王克桢楼另行暂缓，也不计入上述46个。

优先补证：勺园6号宿舍门定位与门槛接地、勺园5号和7号完整阶台、燕南园61号门槛至外地坪的连续关系。资料应能与固定墙角、邻窗或明确朝向配准；无新资料不凭相邻楼或通用模板补造。
